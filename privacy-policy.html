Privacy Policy

This privacy policy describes how the "Video Speed Controls" Chrome extension (the "Extension") handles user data.

Data Collection:

The Extension does not collect any personal or sensitive user data. It does not track your browsing activity or store any information about the websites you visit.

Permissions:

The Extension uses the following permissions:

  • activeTab: To access information about the currently active tab in order to detect video elements.
  • scripting: To inject code into web pages to control video playback.

These permissions are used solely for the purpose of enabling the Extension's functionality and no user data is transmitted or stored.

Data Storage:

The Extension does not store any user data locally or remotely.

Third-Party Services:

The Extension does not use any third-party services that collect user data.

Updates to this Policy:

This privacy policy may be updated from time to time. Any changes will be posted on this page.
